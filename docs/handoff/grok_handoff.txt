2. BACKGROUND THE QUESTIONS DEPEND ON
=====================================================================

Reputation and afterlife (Arceus vs Giratina):
- The user wants the reputation system to decide: Arceus or Giratina, just like Pokemon Outlaw.
- Current implementation (tools/story_yveltal.py, ~line 91-95): when the LEAF stand-in faints, the game checks VAR_REP (0x40E7, reputation + 100, range 0..200, neutral = 100). If VAR_REP >= 100 the player goes to HEAVEN (Arceus), otherwise HELL (Giratina). Same logic as being shot (gun.py 'gotshot').
- Reputation = clamp(100 + blessings - kills + story adjustment, 0..200). Story adjustment VAR_REPADJ (0x40E9) changes with Nero choices. Shop prices scale with reputation; reputation 0 makes the shopkeeper refuse. See CURRENT_WORK.md, Step 6 entries.
- The LEAF stand-in with 1 HP: when she faints, the death/afterlife path runs. Bloody ending hook fixed for blackouts.

Death rule that must be built:
- "Anytime the player is a playable Pokemon, when they lose a battle, they die and go to Arceus or Giratina. If they choose to play normally, they white out and go to a Pokemon Center as normal when they lose a battle." So there are two modes: a "playable Pokemon" run (death permanent) and a normal run (white-out). The mode choice is not yet defined in any spec. Ask the user when building.
