# Leaf throw attack animations (reference set)

Eight approved moves that use Leaf's trainer throw frames as the attacker animation. Timing is in TIMING.md.

- `gifs/`: the approved reference GIFs (960x640, 4x).
- `frames/leaf_frame0..4.png`: Leaf's 64x64 throw frames (RGBA).
- `frames/ball_sprite/`: the Poke Ball sprite used only by Ball Throw (`poke.png` and `poke.gbapal`, top 16 rows).
- No Cormag art, recordings or scripts are included.
